# Flare: Empyrean Campaign — Android / RuStore

An independent Android packaging and compatibility project for the open-source Flare engine and Empyrean Campaign.

Work-in-progress. The native game is **not yet a tested, publishable APK**. See the `port/rustore-android-foundation` branch for Android build automation and source adaptations.

Upstream: https://github.com/flareteam/flare-engine and https://github.com/flareteam/flare-game
