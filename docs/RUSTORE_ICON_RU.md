# Исправление иконки для RuStore (пункт 6.6)

## Что было не так

Витрина версии 0.2.2(4) показывала размытый игровой баннер с надписью,
а AndroidManifest.xml ссылался на `@drawable/ic_launcher` — стандартный
значок пламени из исходников flareteam/flare-engine. Это разные изображения.

## Исправление в сборке

`scripts/rustore_icon.py` использует официальный исходный рисунок
`distribution/flare_logo_icon.png` из **закреплённого** исходного кода
Flare. Скрипт автоматически создаёт:

- `upstream/flare-engine/flare-android-project/rustore-icon-512.png` — непрозрачный
  RGB PNG, 512 × 512, фон полностью заполнен;
- `app/src/main/res/drawable-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher.png`
  — иконки Android всех плотностей из того же самого мастер-изображения.

`scripts/prepare_android.py` запускает генерацию на каждой сборке, а CI
проверяет разрешения, непрозрачность и совпадение с мастер-файлом.
В GitHub Actions мастер-иконка доступна в артефакте `flare-rustore-icon-512`;
если собран publisher-signed APK, она также добавляется к релизу
`android-v0.2.2-rustore-signed`.

## Действия для повторной модерации

1. Скачайте **новый** подписанный APK после успешной сборки и
   соответствующий `rustore-icon-512.png` из **этой же сборки**.
2. В консоли RuStore замените прежнюю размытую иконку витрины на
   `rustore-icon-512.png`.
3. Для версии, по которой была отклонена модерация, загрузите пересобранный
   publisher-signed APK (не debug APK). Проверьте размер файла, package ID
   `com.kalandos240.flareempyrean` и подпись.
4. Отправьте приложение на повторную проверку. Для прежних APK не заявляйте,
   что иконка уже поменялась: установочный APK меняется только после новой сборки.

Требование RuStore: 512×512, до 3 МБ, PNG/JPG, полный фон без прозрачных
краёв и совпадение со значком установленного приложения:
https://www.rustore.ru/help/developers/publishing-and-verifying-apps/requirement-apps

Не удаляйте ключ публикации и не подписывайте обновление другим ключом.
