# VK Реклама / myTarget — монетизация Android-версии Flare

## Что именно подключаем

Для **дохода от показов рекламы внутри игры** выбираем **VK Реклама (ex. myTarget) / myTarget Android SDK**, а не `VK Android SDK` для авторизации и не платные кампании по продвижению игры в RuStore.

Официальные исходники и пример: https://github.com/myTargetSDK/mytarget-android

Публикация SDK на Maven Central: `com.my.target:mytarget-sdk`. На момент подготовки интеграции актуальная версия в официальном README — `5.52.5`. Рекламные блоки используют **числовые slot ID из кабинета партнёра**. Никакие идентификаторы рекламных блоков не должны выдумываться.

## Правила для Flare

1. **Только Android / RuStore.** Не смешиваем с SDK Яндекс Игр, web-сборкой или VK Mini Apps/VK Bridge.
2. **Никакой рекламы во время боя, диалогов, роликов и создания героя**; только в безопасной паузе **после сохранения и выхода из игрового сеанса в меню**. На старте и при загрузке сохранения не показываем.
3. В будущем **rewarded video** можно добавить лишь как добровольную возможность, с выдачей награды **строго по подтверждённому событию onReward**. До согласования баланса Flare награды отключены.
4. Нет интернета, нет рекламного блока, нет загруженного объявления — игра запускается и работает как обычно. SDK не должен блокировать SDL или сохранение.
5. Не чаще одного полноэкранного объявления за несколько минут; отсчёт только по завершённым игровым сеансам. Не показывать рекламу при первом входе.
6. **Без идентификатора площадки и готовой обработки приватности SDK не входит в релиз**. Нельзя рекламировать собственную игру внутри RuStore и считать это монетизацией.
7. Перед активацией: проверить территориальные правила, согласия/возраст, фактические данные/разрешения SDK, политику приватности и соответствие GPL-3.0 движка и LGPL-3.0 рекламного SDK, при необходимости предоставить лицензии и исходники.

## Этапы интеграции

- [x] Выбран SDK myTarget (VK Реклама); проверены официальный репозиторий и API для interstitial/rewarded.
- [ ] Запросить **реальный slot ID полноэкранного рекламного блока** в кабинете монетизации VK Реклама/myTarget. Публичный slot ID отличается от токена доступа рекламного кабинета; токены/ключи в GitHub не публиковать.
- [x] Подготовлена **opt-in** интеграция Java/JNI: `python scripts/prepare_android.py ... --vk-interstitial-slot REAL_SLOT_ID`. Прямая зависимость `com.my.target:mytarget-sdk:5.52.5`, вызов после завершения сеанса игры, перезагрузка рекламы вне игрового процесса. Без slot ID SDK, разрешения `INTERNET` и JNI-хук отсутствуют. **Проверено GitHub CI:** [опциональная сборка VK SDK #38244102004](https://github.com/kalandos240/Flare-Empyrean-Campaign/actions/runs/38244102004) завершилась успешно, включая JNI, Java и APK, после включения AndroidX только для рекламного варианта.
- [ ] Добавить понятный пользовательский экран согласия/настройки приватности. Сейчас `VkAdsBridge.setPrivacyReady()` **нигде не вызывается**, поэтому рекламные запросы и показы намеренно отключены даже в opt-in сборке. Возрастные ограничения и обработку согласия необходимо завершить до релиза.
- [ ] Проверить на физическом Android-устройстве тестовыми объявлениями; отсутствие показа во время игры, обработку закрытия и ошибки загрузки, а также сохранение данных.
- [ ] Включить SDK только после готовности приватности, лицензирования, тестирования и подписания финальной версии.
