# Яндекс Реклама / РСЯ — Android порт Flare

В порт добавлена **опциональная** интеграция Yandex Mobile Ads SDK **8.5.0**, формат interstitial, только Android/RuStore. Официальные источники:
- https://ads.yandex.com/helpcenter/ru/dev/android/quick-start
- https://ads.yandex.com/helpcenter/ru/dev/android/interstitial
- https://ads.yandex.com/helpcenter/ru/dev/android/gdpr

**Релиз без рекламы** (как сейчас):

```bash
python scripts/prepare_android.py --engine upstream/flare-engine --game upstream/flare-game
```

**Сборка с РСЯ** (после получения настоящего текстового ad unit ID):

```bash
python scripts/prepare_android.py --engine upstream/flare-engine --game upstream/flare-game \
  --yandex-interstitial-unit R-M-REPLACE-WITH-YOUR-REAL-ID
```

**Обе сети** (когда получены обе реальные ID):

```bash
python scripts/prepare_android.py --engine upstream/flare-engine --game upstream/flare-game \
  --vk-interstitial-slot 123456 \
  --yandex-interstitial-unit R-M-REPLACE-WITH-YOUR-REAL-ID
```

Идентификаторы выше служат **образцами синтаксиса**, **не** действующими рекламными блоками. Не публиковать такие сборки и не считать наличие SDK доказательством показа рекламы.

В opt-in варианте приложение включает зависимость `com.yandex.android:mobileads:8.5.0`. В Manifest **отключена автоматическая инициализация**, чтобы не начинать работу SDK до явного выбора пользователя. После разрешения вызываются `YandexAds.setUserConsent(true)`, `YandexAds.initialize()` и загрузчик `InterstitialAdLoader`. В случае отказа SDK Яндекса не инициализируется приложением. Нужно учитывать, что полная корректность обработки согласий (включая несовершеннолетних и местные законы) требует проверки перед публикацией.

Правила монетизации:
- Не мешать бою, диалогам, инвентарю и роликам: реклама возможна лишь после сохранённого выхода в главное меню.
- Сеанс должен длиться хотя бы 3 минуты, между показами данной сети — хотя бы 4 минуты.
- При одновременном использовании VK и Яндекса сети **чередуются** по игровым сеансам; не показываются две подряд.
- Если рекламы нет или сеть недоступна, игра продолжает работать без неё. SDK не блокирует запуск.
- **Для запуска показов в существующем APK не достаточно создать блок в кабинете**: в текущей схеме ID передаётся на этапе сборки. Реальное удалённое включение без обновления потребует отдельного доверенного конфигурационного сервиса, который сейчас не настроен.
- Для загрузки в RuStore нужны реальные идентификаторы, политика конфиденциальности, подтверждённый пользовательский выбор, возрастная маркировка, тест на физических устройствах, соответствие условиям лицензий SDK и подписанная сборка.

CI: `.github/workflows/android-vk-ads-compile.yml` дополнен сборкой варианта с Яндексом и обоими SDK **исключительно для проверки компиляции**.
