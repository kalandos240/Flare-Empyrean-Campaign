# Яндекс Реклама / РСЯ — Android порт Flare

В порт добавлена **опциональная** интеграция Yandex Mobile Ads SDK **8.5.0**, формат interstitial, только Android/RuStore. Официальные источники:
- https://ads.yandex.com/helpcenter/ru/dev/android/quick-start
- https://ads.yandex.com/helpcenter/ru/dev/android/interstitial
- https://ads.yandex.com/helpcenter/ru/dev/android/gdpr

**Текущая сборка Android 0.2.3:** РСЯ подключена через рекламный блок `R-M-20327058-1` (межстраничная реклама). ID публичный и передаётся при сборке, а не скачивается динамически. Ранее опубликованные APK автоматически не изменятся.

```bash
python scripts/prepare_android.py --engine upstream/flare-engine --game upstream/flare-game \
  --yandex-interstitial-unit R-M-20327058-1
```

**Сборка без рекламы** по-прежнему доступна: без флага `--yandex-interstitial-unit` и без `--vk-interstitial-slot` ни SDK, ни разрешение INTERNET, ни нативные рекламные хуки не добавляются.

**Обе сети** можно включить одновременно, если получен настоящий VK slot ID; выдуманные ID для релиза запрещены. Тестовый CI по-прежнему использует подставные ID и проверяет только компиляцию.

В opt-in варианте приложение включает зависимость `com.yandex.android:mobileads:8.5.0`. В Manifest **отключена автоматическая инициализация**, чтобы не начинать работу SDK до явного выбора пользователя. После разрешения вызываются `YandexAds.setUserConsent(true)`, `YandexAds.initialize()` и загрузчик `InterstitialAdLoader`. В случае отказа SDK Яндекса не инициализируется приложением. Нужно учитывать, что полная корректность обработки согласий (включая несовершеннолетних и местные законы) требует проверки перед публикацией.

Правила монетизации в Android 0.2.3:
- **Только естественные паузы:** выход в главное меню после сохранения, первая смерть персонажа и завершённый переход на другую карту. Не показывать в бою, при разговоре, в инвентаре или внутри ролика.
- Первый показ возможен не раньше **2 минут 30 секунд** после начала игровой сессии. Между попытками полноэкранного показа — минимум **2 минуты 30 секунд** глобально для VK и Яндекса, даже после перезапуска приложения. Не показывать на начальной загрузке карты.
- Реклама показывается только при явном разрешении пользователя и наличии заранее загруженного объявления; если блок не отдаёт рекламу или SDK не готов, игра продолжается без ожидания. Таймер не обещает показ каждые 150 секунд, а только ограничивает частоту.
- При двух сетях сеть выбирается поочерёдно при начале игровой сессии; одновременно две рекламы не показываются. ID VK в обычной сборке не указан, поэтому работает только РСЯ.
- Смена карты по игровому событию с цепочкой переходов не должна вызывать рекламу посреди загрузки; первая карта после запуска пропускается.
- **Перед загрузкой в RuStore:** завершить модерацию приложения в РСЯ, опубликовать корректную политику конфиденциальности, проверить согласия и возраст, протестировать реальные показы/закрытия и сохранения на Android, сверить возрастной рейтинг и сведения о рекламе в карточке RuStore. Активный статус блока не подтверждает реальную доставку объявления.
- Реклама в старой APK не появится удалённо: необходимо обновить версию приложения в RuStore.

CI: `.github/workflows/android-vk-ads-compile.yml` дополнен сборкой варианта с Яндексом и обоими SDK **исключительно для проверки компиляции**.

При сборке с обеими сетями выбор следующей сети сохраняется в локальных настройках приложения: если пользователь закрывает приложение между игровыми сеансами, порядок чередования VK / Яндекса не сбрасывается.
